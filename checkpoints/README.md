# Checkpoints

This release provides two pretrained SPath checkpoints:

- `spath_vrw23.pt`: trained on VRW23 / VR Video Quality in the Wild.
- `spath_cvpr18.pt`: trained on CVPR18 / VR-EyeTracking.

The model files are hosted outside the Git repository. Download them from Google Drive and keep these relative paths:

- [spath_vrw23.pt](https://drive.google.com/file/d/1IwzIUrDriTewD2qdHietvYtH4i0kqFrM/view?usp=drivesdk)
- [spath_cvpr18.pt](https://drive.google.com/file/d/1wv58V_AJdAuEjx-Yay4Xukdj-Ib3IcuG/view?usp=drivesdk)

```text
checkpoints/spath_vrw23.pt
checkpoints/spath_cvpr18.pt
```
